# Czcionki

- `Fredoka-Variable.ttf`: Fredoka (font zmienny, osie `wght` 300–700 i `wdth` 75–125), autorzy: The Fredoka Project Authors. Źródło: https://github.com/google/fonts/tree/main/ofl/fredoka (pobrane 16.11.2026, plik `Fredoka[wdth,wght].ttf`, tu bez nawiasów w nazwie).
- Licencja: SIL Open Font License 1.1, pełny tekst w `OFL.txt`. Pozwala na komercyjne użycie czcionki w drukowanych książkach.

Napis na stronie „This book belongs to…” (FR-14) używa wariantu `SemiBold` (`belongs_to_page.font_variation` w `config/settings.yaml`).
